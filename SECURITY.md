# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via [GitHub's private vulnerability reporting](https://github.com/fabricity/vite-bundle/security/advisories/new).

We aim to respond within **72 hours** and will work with you to release a fix as quickly as possible.
